# 结果展示与 Excel 交付规范

结果可直接在对话中展示，也可生成 Excel；用户明确指定时遵从。无论采用哪种方式，信息范围、证据和意见标准一致。

## 直接展示模式

- 用 Markdown 表格或当前环境支持的交互式表格展示全部合适候选，不得只列“前三名”或摘要。
- 主表至少包含：意见分组、立创商品编号、厂家型号、品牌、封装、关键电气参数、目标数量单价、预计物料金额、库存、起订量/购买增量、风险、待核验项、商品页链接和查询时间。
- 表格过宽时拆为“电气参数”和“市场因素”两张表，以立创商品编号关联；不要用删列解决宽度问题。
- 在主表后分别展示待核验候选、主要排除项与检索完整性说明。价格阶梯较多时可折叠成分组列表，但不能只保留最低价。
- 候选过多而不适合一次阅读时，可分段连续展示或改用 Excel，并在对话中明确说明完整数据的位置；不得静默截断。

## Excel 模式

输出文件名包含器件类别与查询日期，例如 `DC-DC_立创选型_2026-10-14.xlsx`。不得用 CSV 代替 Excel 交付物。

### 工作表

### 1. 选型说明

记录：需求原文、结构化硬约束、偏好、目标采购数量、预算/成本口径、采用的假设、查询开始/结束时间（Asia/Shanghai）、来源限制、完整性声明、评级方法和免责声明。

### 2. 全量候选

每行一个 SKU。固定字段至少包含：

- 序号、意见分组、一句话意见、硬约束结论、信息置信度
- 立创商品编号、厂家型号、品牌、商品分类、商品描述
- 封装/外形、安装方式、包装方式、包装数量
- 当前库存、库存覆盖倍数、起订量、购买增量、目标采购数量
- 目标数量单价、预计物料金额、是否需向上取整、向上取整后采购量、向上取整后金额、预计余料
- 电气适配评级、设计裕量说明、成本评级、供应评级、风险摘要、待核验项
- 商品页链接、规格书链接、查询时间

在这些固定列后，为本次器件类别增加独立电气参数列。参数名必须带单位，例如 `输入电压最小值 (V)`、`导通电阻典型值 (mΩ)`；不要把所有参数塞进一格。区分典型值、最大值、测试条件和推荐工作条件。没有数据时留空或写“未提供”，不要填 0。

主表只放通过硬约束的候选。参数缺失导致无法确认者不混入主表。

### 3. 待核验候选

列结构尽量与“全量候选”相同，并额外列出缺失参数、为何可能符合、所需核验动作。避免因为页面信息不足而静默丢弃可能的候选。

### 4. 价格阶梯

每个 SKU 的每个可见阶梯占一行：立创商品编号、厂家型号、数量下限、数量上限、网页显示单价、币种/税费口径（仅按页面明示）、库存、查询时间、商品页链接。这样保留原始市场快照，不只留下一个计算结果。

### 5. 排除项

记录近似但未入选的 SKU、商品链接、触发的硬约束、排除理由及证据字段。无需收录明显无关的搜索噪声。

### 6. 检索记录

记录检索式、类别与筛选条件、分页/结果范围、访问时间、结果数、失败或受限页面、去重规则和完整性备注。此表用于证明“全部候选”的范围。

### 计算与格式

- 将单价、数量、库存、电压、电流、温度、尺寸等保留为数值列，单位放在表头；不要把 `¥0.42` 存成纯文本。
- `预计物料金额 = 目标采购数量 × 对应阶梯单价`。
- 若存在购买增量，`向上取整后采购量 = CEILING(MAX(目标采购数量, 起订量), 购买增量)`；当页面未提供规则时不要臆造。
- `库存覆盖倍数 = 当前库存 / 目标采购数量`；目标数量缺失时留空。
- 通过硬约束用绿色、待核验用黄色、存在明确风险用橙色、排除用红色。颜色不能代替文字结论。
- 对标题行启用自动筛选并冻结；为型号、结论、风险和关键参数设置合理列宽与换行；商品页和规格书使用可点击超链接。
- 不隐藏候选行，不只展示“前几名”。可以额外排序，但原始全量候选必须完整保留。
- 生成后重新读取工作簿，检查工作表名称、行数、公式、超链接和关键字段；若可渲染，则检查是否出现截断、乱码或不可读布局。

## 两种模式通用的意见写法

每条意见同时说明优势、代价与适用前提，例如：“电压裕量较高且目标数量库存充足；单价高于同组中位数，适合优先做高可靠性样机验证。”避免“最佳”“完美”“直接选它”等替用户拍板的措辞。
